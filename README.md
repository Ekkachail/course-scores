# ระบบคะแนนรายวิชา

เว็บรายงานคะแนน ส่งการบ้าน และเช็คชื่อด้วย QR สำหรับรายวิชา — HTML + JavaScript ล้วน (ไม่ต้อง build)
ข้อมูลเก็บใน [Supabase](https://supabase.com) (ฐานข้อมูล + login + ที่เก็บไฟล์) · เว็บโฮสต์ฟรีบน GitHub Pages

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ |
| `config.js` | URL และ publishable key ของ Supabase (ใช้ในเว็บได้ — **ห้ามใส่ secret / service_role key**) |
| `app.js` | login, ตารางคะแนน, หมวด/รายการ, เกณฑ์เกรด, รายชื่อ, หน้านิสิต |
| `hw.js` | สั่งงาน / ส่งงาน / ดาวน์โหลดทั้งหมด / ส่งไฟล์ตรวจกลับ |
| `att.js` | เช็คชื่อด้วย QR |
| `style.css` | หน้าตา |
| `sql/` | สคริปต์สร้างฐานข้อมูล — รันใน Supabase SQL Editor ตามลำดับ 01 → 07 (02 เป็นข้อมูลทดลอง ไม่ต้องรันก็ได้) |

## ความปลอดภัย

สิทธิ์ทั้งหมดคุมด้วย Row Level Security ในฐานข้อมูล: นิสิตเห็นเฉพาะคะแนน/ไฟล์ของตัวเอง
และเฉพาะรายการที่อาจารย์ประกาศแล้ว · การเช็คชื่อและเวลาส่งงานตรวจโดยเซิร์ฟเวอร์

## ตั้งค่า Supabase หลังนำเว็บขึ้น

Authentication → URL Configuration
- **Site URL**: URL ของเว็บนี้บน GitHub Pages
- **Redirect URLs**: URL ของเว็บนี้ และ `http://localhost:5173` (ใช้ทดสอบในเครื่อง)
